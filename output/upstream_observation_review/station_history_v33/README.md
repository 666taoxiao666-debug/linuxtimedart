## 时间语义

- `ob_time` 用UTC小时定位。小时天气表包含小时内/小时终了的不同观测要素，不能把各列都称为“整小时均值”。风向是风的来向；风速字段声明knots，审计按1852/3600转m/s。
- 历史MIDAS说明中，SYNOP风速通常为10分钟平均，变化时可能使用较短区间；`q10mnt_mxgst_spd`是10分钟最大阵风。观测名义时间、实际测量区间、报文发布/收到时间是不同概念。
- `ob_time + 1/3/6h`只是模拟可用时间。归档版本可能经过后续修订，没有历史接收日志，不能证明对应值在当年发布时已经可用。
- 来源：[CEDA小时天气表](https://artefacts.ceda.ac.uk/badc_datadocs/ukmo-midas/WH_Table.html)、[MIDAS Open指南](https://help.ceda.ac.uk/article/4982-midas-open-user-guide)、[历史MIDAS用户指南§2.4、3.3、6.1](https://artefacts.ceda.ac.uk/badc_datadocs/ukmo-midas/ukmo_guide.html)。最后一项为历史指南，不能替代每条报文的实际时钟证据。

## 到达时间与支持率

分母固定61,335个日历发布时刻（移除最初29h和最后4h）。不读取标签，因此不知道实际训练合格窗口的分母。方向取同观测时刻的站点自身来向，缺失时用同一时刻区域圆均值；上风向要求投影距离大于0，本站风速小于2m/s不提供物理支持。没有另加60度硬筛选。

本次计算 `T_adv = d_parallel / (3.6 * κ * max(v,2))`，v为同观测时刻上风向均速；无上风向可用速度才回退区域均速。这是代理运动时间，不是测得传播时间。κ=1是预设参考，0.5和4只是端点敏感性，未据结果选κ。

参考κ=1、892,964个活跃站小时的T_adv分位数：P5=0.437h、P25=2.043h、P50=4.188h、P75=7.002h、P95=12.204h、P99=16.465h、最大20.634h。κ=0.5/4的中位数分别8.377/1.047h。

以下支持率定义为：某发布时刻的历史token中，至少一个活跃token的中心 `r_remaining=T_adv-age` 落入 `[h−1,h]`。它未对横风距离权重设下限，故不能直接解释为有用信息比例。

κ=1、固定过去24h时，r∈[0,4]占全部活跃历史token的11.64%/8.63%/4.77%（延迟1/3/6h）；最新可用24h时为11.64%/7.91%/3.78%。这与“每个发布时刻至少一个支持”的分母不同，不能混报。

另计算软高斯积分核：σ=max(1,0.5T_adv)，乘方向余弦与30km横风尺度高斯项。固定content score=0、null权重=1，q按可用风token数均值归一后，参考非null质量M=qmean/(1+qmean)。延迟1h的M中位数按h1–4约0.003963/0.003443/0.002872/0.002394；不是训练后的注意力，也不是校准概率。高中心覆盖与小M并不矛盾：历史token多、横风权重可很小。
