# Kelmarsh：跨风机响应加权案例执行器

日期：2026-10-15。用户授权继续分析、修改、推送并在服务器训练。
本轮目标是检验案例响应权重能否改善预测，不修改数值底座、标签或原效用门槛。

## 已有证据与本轮机制

v9已完成、主要验收失败。正式输出完全等于共同底座：MAE101.888844、RMSE155.471020、
R²0.78323587，介入0%。训练校准h2虽然宏平均获益，但只有3/5风机获益，不足原定2/3。
这不是未启动训练，也不是证书算错；不能通过降低门槛放行。

本轮先做CPU只读训练审计：只读取已登记的early训练段和原案例，不读取outer/test标签。
event0/state5有352个物理匹配query、151个原案例。标准化键距离与未来功率响应差异的
相关系数为0.259979；跨风机最近32个案例的响应MSE为0.0214996，对所有跨风机案例为0.0246746。
因此距离并非无效，但相近输入仍可能有不同响应。固定跨风机案例读出h1 MAE146.147171，
差于同窗口底座145.404212；h2为210.290865，优于214.773167。不能把这一训练关联写成迁移保证。

新执行器`models/ResponseCaseAttention.py`对固定局部案例池学习每个步长的响应相似度权重。
它没有自由数值输出头：值必须是实际案例的未来功率增量，输出是这些值的加权读出、
相对于实际共同底座的有界提案，以及两个0～1执行系数。查询特征和候选池不读取查询标签。
训练和推理统一排除同风机案例，原标准化空间仍用于32个候选的预筛和支持量判定；
可学习编码器只重排局部案例，不能搜索任意未来案例。

编码器通过同一MIXED损失学习未收缩的提案，避免零置信起点阻断检索梯度；每轮后只在
原memory+early拟合段求解两个凸收缩系数，限制拟合段MAE/MSE均不差。求解器不是阈值网格搜索。
选epoch仍使用原115个训练窗口，证书仍使用稍晚110个训练窗口。校准/outer标签不拟合编码器或系数。

这是一次完整读出机制替换，不声称仅改一个参数，也不声称同参数消融。新增固定距离核读出
FixedKernel使用相同跨风机池、案例值、episode先验和两个拟合系数，不训练神经编码器；
它是机制对照，不是参数量匹配对照。另复用已完成的自由Wiki、零记忆与v8/v9输出，不重训。

## 预声明实验与边界

协议：`configs/kelmarsh_response_attention_protocol_v10.json`。
入口：`scripts/train/Kelmarsh_launch_response_attention.sh`。
预算：fold1 seed2024一个新编码器20epoch，另一次解析FixedKernel系数拟合；不扩展fold/seed。
案例来源、标签预算、32邻居、0.95支持分位数、min24窗口/min3风机/2/3正收益要求不变。
初始执行系数为零，保留epoch0共同底座回退。正式结果必须为选择性输出；raw不得事后顶替。

实际执行器证书绑定：原案例ID、新query/view与源码哈希、编码器和执行系数检查点、
原数值门、底座/scaler和实际校准输出。输出另存case indices、源风机、权重、提案、
执行系数和delta，允许逐点复算，而不以“用了attention”代替证据。

主要验收：正式ResponseAttentionSelective的MAE和RMSE都优于共同底座/Persistence、
v9正式Wiki、v8正式Wiki、自由Wiki、零记忆正式输出和FixedKernelSelective。
报告MAE/MSE/RMSE/R²、双Skill、容量容差命中率、逐步长误差、coverage、selected gain、
harm、abstention、时间块bootstrap/Newey–West和预测图。outer仍是被历史开发查看的一折，
不是独立确认。本轮不访问封存test，不改原始功率标签，不把神经检索本身包装成已证实新颖性。

## 【必须立即修复Top 5】

1. 输入相近不等于响应相近：检验监督式案例权重而非再增加硬编码摘要。
2. 拟合支持半径排除同风机、历史推理却允许同风机：本轮对照统一排除，避免两套检索条件混同。
3. 零执行系数不能杀死检索梯度：提案监督与执行收缩分开，保持原标签预算。
4. 新读出必须有新证书和可复算输出；不能借用原专家收益或只记录名义backbone。
5. 固定距离对照、自由Wiki/零记忆对照及负结果必须同时保留；不事后更改正式评价对象。

## === 详细问题清单 ===

- **严重级别**：P2（模型设计假设）。
  **位置**：`utils/kelmarsh_short_dynamics_wiki.py -> candidates`与
  `utils/local_transport_event_wiki.py -> _neighbors`。
  **触发条件及证据**：所有键等权距离，训练早段距离/响应差异相关0.26，h1固定读出比底座差。
  **影响**：近邻平均可混入方向/幅度不适合当前query的案例。
  **修复**：响应监督的局部案例加权；保持真实值、物理支持和成熟时刻。
  **验证**：权重/value逐点复算、固定核对照和新的实际输出收益证书。
  **置信度**：对现象高，对能否改善为待实验。

- **严重级别**：P2（部署/拟合条件不一致，不等同于标签泄漏）。
  **位置**：旧`_neighbors`只在fit半径使用`excluded_turbines`，旧推理未传该参数。
  **触发条件及证据**：源风机1–5可在推理检索自己历史案例，持出风机6没有此选项。
  **影响**：支持半径和推理池条件不同，跨风机结论混入同风机历史便利。
  **修复**：新view在fit和推理均排除query风机；不重写旧实验。
  **验证**：case_units与query units逐项不等，所有实际trace可复核。
  **置信度**：高。

- **严重级别**：P2（优化路径）。
  **位置**：新`ResponseCaseAttention.components`、runner `train/fit_alpha`。
  **触发条件及证据**：若只对alpha×提案监督且alpha=0，提案编码器初始梯度为零。
  **影响**：严格底座起点可能阻碍有用检索学习。
  **修复**：直接监督有界提案，执行alpha只在拟合段作凸求解；保持后续选择/校准隔离。
  **验证**：alpha为零时执行delta严格零，但提案损失对编码器有非零梯度。
  **置信度**：高；不把这一数学性质说成旧模型失败的唯一原因。

- **严重级别**：P1（结论/证据边界）。
  **位置**：协议`primary_success/limitations`及最终报告。
  **触发条件及证据**：多轮同一开发外层，不是新确认集；5风机窗口高度相关。
  **影响**：一次正结果也不能作为独立显著性或因果迁移保证。
  **修复**：预声明单轮预算、完整正式/raw/对照和配对统计，证书与实际对象绑定。
  **验证**：协议哈希、标签分区、旧结果保留、完成后独立复算。
  **置信度**：高。
