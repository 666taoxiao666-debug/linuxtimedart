## 目标

找出大模型在本任务中**是否、在什么条件下**有用，并为三种写法各准备好可检验的标准：
1. 显著优于强基线：写成贡献；
2. 精度相当，并且有别的好处（少数据、免特征工程）：用事先定好的等效界，写成"相当"；
3. 两者都不满足：写成负结果。
不允许事后改写法。

## 依据（文献要点，链接见 DECISIONS「阶段 X3」）

- **协变量和长上下文是用好时序基础模型的关键。**
  - 建筑能耗的研究发现，零样本时把上下文加长，就能达到接近微调的效果；
  - 电网负荷的研究发现微调提升明显，但零样本不如专门训练的模型；
  - FETS 基准称，带协变量的 Chronos-2 在风电和光伏上胜过精调的 XGBoost（二手资料，待核）。
- **基础模型的公认长处是冷启动和少数据：** WindFM、光伏冷启动研究（440 个站）都显示，在没有本场训练数据时胜过专门训练的模型。
- **强基线上很难再提升：** CRAFTER（2026）发现，大模型纠错特征的增益取决于基础模型还剩多少可修正的误差，主要集中在弱基础模型上。这和本项目 L1、A 线的负结果一致。
- **我们自己的数据：** Chronos-2 零样本，上下文从 24 h 加到 168 h，Kelmarsh 测试 MAE 从 190.1 降到 163.5；LUG 是 145.3。微调 B1 之前因为显存不足失败（另一个进程占了 20.6 GB），不是代码缺陷。

## 假设与判定标准（讨论稿，Codex 可以提修改）

**共同设置**
- 开发段切分沿用 X2 的 V1、V2；参照臂是 LUG（第 1 轮冻结的 3 个 seed）；Chronos-2 版本 29ec3766，清单 SHA 758b5c25。
- 测试集都已暴露，只评一次，标"探索性"。
- 统计方法和合并规则同 X2（R1-B2）：块 bootstrap，相对值，逆方差合并；CI 宽度为 0 或非有限值，记技术失败。
- 两个"正结论"问题 Q3、Q4 合在一起做 Bonferroni 校正（2 个问题，z = 2.241）。

**Q1：长上下文的零样本（只描述，并为 Q2、Q3 选上下文长度）**
- 上下文取 {168, 512, 1024} h，GFS 作未来协变量，过去协变量和 A3 相同。
- 更早的历史从冻结样本包的逐小时网格里取，没有的就记 NaN（同 run_x1.history_grid），绝不读未来标签。
- 在 V1 上按中位数预测的 MAE 选上下文长度；报告 V2 上和 LUG 的差距。

**Q2：微调（判定"是否相当"）**
- 在拟合段上全参数微调（官方 fit 接口），上下文取 Q1 选出的长度，学习率 1e-6，1000 步，每 100 步在 V1 上算一次 MAE，挑最好的检查点。
- 显存：先在 nvidia-smi 上确认有 ≥ 12 GB 空闲再启动；不够就改用 LoRA（官方接口支持的话，待确认），或者把 batch 降到 64，并如实记录。
- 判定（V2，事先设定）：
  - 合并相对增益的 CI 下界 > −1%：记为"和 LUG 相当"（非劣效，等效界 1%）；
  - CI 下界 > 0：记为"优于 LUG"；
  - 两者都不满足：负结果。

**Q3：和 LUG 集成（判定"是否提升"）**
- 预测 = w × LUG + (1 − w) × Chronos-2 的中位数，w 从 0 到 1、步长 0.05，每个风场在 V1 上选。
- Chronos-2 成员有两个候选：Q1 选出的零样本、Q2 微调后的模型，在 V1 上选其一。
- **对照（必须有）：** LUG 和 N_v1（TSMixer，X2-B2 的预测）按同样方法集成。只有"LUG + Chronos"比"LUG + N_v1"更好，才能说"是大模型带来的提升"；否则只能说"任何第二个模型集成都有提升"。
- 判定（V2，Bonferroni）：
  - LUG + Chronos 对 LUG：每个风场都提升 ≥1%，合并 CI 下界 > 0；
  - 并且 LUG + Chronos 对 LUG + N_v1：合并 CI 下界 > 0。
- 只用已有零样本预测的部分不需要服务器：A3 的 168 h 预测已经在本地，可以由 Claude 在方案冻结后用 numpy 计算。

**Q4：新风场少数据（判定"在冷启动下是否有用"）**
- **设定：** 对每个风场，假装它是新风场，本场只有验证年之前最后 k 个月的数据，k ∈ {1, 3}，主判定用 k = 1。判定同样只看 V2。
- **臂：**
  - L_k：LightGBM，只用本场 k 个月训练（网格同 A1，在 V1 上选）；
  - L_k+X：LightGBM，用另外两个风场的全部拟合段，加上本场 k 个月训练。功率按额定归一化；机组编号改为"风场 + 机组"；HoT 的改造通道在其他风场记 0（具体做法待确认）；
  - C_zs：Chronos-2 零样本，上下文不超过本场已有的历史（k = 1 时最多约 720 h）；
  - C_ft：Chronos-2 用本场 k 个月微调（可选，看显存和时间）。
- **判定（k = 1，Bonferroni）：** 最好的 Chronos 臂对最好的 LightGBM 臂（L_k 和 L_k+X 中较好的那个），每个风场的增益 > 0，并且合并 CI 下界 > 0。k = 3 和全量数据只作描述（画学习曲线）。
