## 阶段名

X2（2026-11-16，第二版）：分两部分。A 部分在 LightGBM 底座上做信息消融，并检验候选机制 ANI；B 部分把用户以前的两个模型移植过来，做底座筛选。**本轮只交 Codex 审方案、审代码、在服务器上跑 torch 单测，不训练、不评估。**

## 目标

1. A 部分：在同一 LightGBM 底座上，分开量化本场、上游、GFS 各自的贡献；检验 ANI 在完整 A1 信息集之上是否还有增益；ANI 通过后，再检验它能否迁移到神经网络底座。
2. B 部分：在统一的输入、切分、训练配方和评估口径下，比较 6 种底座：
   - LightGBM；N（TSMixer）；
   - TCN-GRU，以及加域对抗的 TCN-GRU（项目 A）；
   - CNN、BiLSTM，以及它们和 LightGBM 的堆叠融合（项目 B）。
   - 选出论文的主底座。
3. 定位原则：换底座本身不算创新；只有 ANI 在两类预测器上都通过，才能称为"可迁移的方法"；否则论文按高质量实证研究来写。

**A 部分：LightGBM 消融和 ANI**
- **ANI 的定义：**
  - 功率曲线 PC_i：每台机单独建，只用拟合段；横轴是 GFS 历史通道的原始风速（从逐小时数组取，保留 NaN），纵轴是实测功率；0.5 m/s 分箱取中位数，每箱至少 30 个样本，箱间线性插值，超出范围取端点。
  - 有效箱少于 2 个的机组，改用全场合并的曲线；全场合并后仍少于 2 个，该场 ANI 和 PCL 全记 NaN（R1-S4）。
  - 特征（g(t0+h) 取 gF 第 5+h 列，任一输入无效就记 NaN）：
    - PCL（对照，5 个）：PC(g(t0+h))（h = 1–4）和 PC(g_hist(t0))；
    - ANI（8 个）：ΔP_h = PC(g(t0+h)) − PC(g_hist(t0))，以及锚定预测 clip(P(t0) + ΔP_h, 0, 额定)。
  - PCL 和 ANI 都只是对 A1 已有输入做确定性变换，不引入新信息。
- **臂：** L0（只有本场）、LU（加上游）、LG（加 GFS）各 1 个 seed；LUG（= 完整 A1 信息集）、LUG+PCL、LUG+ANI 各 3 个 seed（门槛用 3 个 seed 的平均损失；消融描述统一只用 seed 2024，见 R1-S1）。
- **调参：** 网格与 A1 相同（4 组）；用 seed 2024 在 V1 上选，其余 seed 用选中的组合；早停 200 轮，固定 8 线程。
- **门槛（只看 V2，事先设定）：**
  - **合并规则（R1-B2，事先定死）：**
    - 各场用 paired_loss_statistics 算出增益 g_f 和 bootstrap CI，标准误 se_f = (CI 上界 − CI 下界) / (2 × 1.96)。
    - 换算成相对值：r_f = g_f / L_f，s_f = se_f / L_f，其中 L_f 是该场参照臂在 V2 上的平均损失。
    - 权重 w_f = 1 / s_f²；合并值 r = Σ w_f r_f / Σ w_f；合并标准误 = √(1 / Σ w_f)；合并 CI = r ± 1.96 × 合并标准误。
    - 任何一场的 CI 宽度为 0 或不是有限值，该门槛记为"技术失败"，不判通过。
  - 门槛 1：LUG+ANI 对 LUG，每个风场都降低 ≥ 1%，并且合并 CI 下界 > 0。
  - 门槛 2：LUG+ANI 对 LUG+PCL，合并 CI 下界 > 0，并且至少 2 个风场为正。通过只能说明"整套 ANI 表示（差分加锚定）比 PCL 好"，不能归因到锚定这一项（R1-B1）。
  - 门槛 3：门槛 1、2 都通过后才做。在 N 和 B 部分最好的神经网络底座上各加 ANI，按门槛 1 的规则判定。
    - 神经网络里，NaN 用拟合段的均值填补，并额外加 2 个缺测标志通道（GFS 预报、历史各一个），再像 GFS 常数一样沿 24 步广播（R1-S5）。
- **结论怎么写：**
  - 三关都过："可迁移的信息利用方法"（开发期证据）。
  - 只过 1、2：整套 ANI 表示只对树模型有效。
  - 只过 1：功率曲线这类特征工程。
  - 门槛 1 没过：负结果。
  - 三场都为正、但有风场不足 1%：最多再做 2 轮。每轮要先登记、交审，不能自动运行；重复使用 V2 也不能称为独立确认（R1-S2）。候选变体：横轴改用机舱风速；改用比值形式。
- **只描述：** 四项信息贡献 U = LU − L0、G = LG − L0、U|G = LUG − LG、G|U = LUG − LU，和 N 上的 2×2 结果对照。

**B 部分：底座筛选（用户 11-16 新增，代码在 models/LegacyBases.py）**
- **6 个底座，输入完全相同：** x50（HoT 再加改造通道），过去 24 h，预测未来 1–4 h，标签是原始 kW，都用冻结的拟合段归一化。

| 底座 | 来源 | 训练 |
|---|---|---|
| LUG | A 部分的 LightGBM | 4 组网格 × 3 个 seed |
| N_v1 | TSMixer，按 V1 早停重训 | 3 个 seed |
| TCNGRU | 项目 A：TCN 通道 (64, 128, 128, 64)，核 7，dropout 0.1；TCN → GRU → MLP | 3 个 seed |
| DATCNGRU | TCNGRU 加域判别器 | λ_end ∈ {0.005, 0.05}，在 V1 上选，各 3 个 seed |
| CNN、BILSTM | 项目 B 的两个网络，按原结构移植到 PyTorch | 各 3 个 seed |
| FUS | {CNN、BILSTM、LUG} 的 Ridge 堆叠 | 只在 V1 上拟合，然后冻结 |

- **神经网络统一配方：** 与 N 完全相同——AdamW，lr 1e-3，wd 1e-4，cosine，batch 64，最多 40 轮，耐心 5 轮，按 V1 MAE 早停；损失 0.8 MAE + 0.2 MSE；梯度裁剪 1.0。两个 TCN 臂第 16 轮（40% 预热）以后才允许早停，避免预热期就停掉。
- **对旧代码的五处修复：**
  1. 融合权重不能用评估段的真值。
  2. 和 3. 归一化统一用冻结的拟合段统计量。
  4. 域对抗：GRL 系数只乘一次，域损失权重为 1，记作"DA（标准 GRL）"。原代码乘了两次，实际系数是 λ²，等于 2.5e-5。
  5. 堆叠不能用样本内预测或普通 KFold，改为在 V1 上按时间顺序前向切块。
  - 另外：去掉输出截断到 [0, 1]；72/6 步改为 24/4 步；不加日历特征，以保证各臂信息相同。
- **域标签：** 按原代码，把拟合段按时间等分成 3 段。
- **主底座的选择（事先设定）：** 以 LUG 为参照，取 V2 上三场平均相对 MAE 最低的底座；和 LUG 相差不到 1% 时选 LUG，因为它更简单、更便宜。
- **只描述：** DATCNGRU 对 TCNGRU（看域对抗有没有用）；FUS 对最好的单个成员；训练成本和参数量。

1. V2 样本少，1% 的差异单场可能测不出来，所以用三场合并的 CI 判定。
2. ANI 和已有思路（MOS、数值预报订正、持续法与数值预报混合）接近，新意有限，写论文前要先查文献。
3. 调参预算不完全对等：LightGBM 有 4 组网格，神经网络只有 1 组配置。论文里如实写明。
