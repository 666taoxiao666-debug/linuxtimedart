## 阶段名

X2（2026-11-16）：在 LightGBM 底座上做信息消融，并用一个事先冻结的候选机制（ANI）做验证。**本轮只交 Codex 审方案，不启动新实验。**

## 目标

1. 在同一个 LightGBM 底座上，分开量化本场 SCADA、上游观测、GFS 各自的贡献，检验在神经网络 N 上得到的信息结论，换一种预测器后是否仍然成立。
2. 检验候选机制 ANI 能否在完整 A1 信息集之上再带来增益。只有相对完整 A1 仍有增益，才算机制本身的价值；"新底座 + 新机制"去和旧 N 比，不算数。
3. 只有 ANI 在 LightGBM 和 N 两种预测器上都通过，才能称为"可迁移到不同预测器的信息利用方法"。否则论文如实定位为高质量的实证研究；更换底座本身不算创新。

## 假设与判定标准

**前提一：底座选择只依据开发数据。**
- A1 与 N 的开发验证 MAE（kW）：Kelmarsh 133.50 对 135.19（−1.3%），Penmanshiel 182.91 对 190.21（−3.8%），HoT 175.51 对 182.22（−3.7%）。
- 测试集结果只作描述：A1 比 N 低 1.21（不显著）、7.97、6.37、6.33 kW。
- RMSE 和 R² 两者基本持平：HoT 2024 的 RMSE 为 330.1 对 331.4。也就是说，A1 的优势主要体现在 MAE 上，和它用 L1 目标有关。论文要写清楚这一点。

**前提二：已有成果盘点**

| 类别 | 内容 | 实验支持情况 |

**ANI 的定义**（锚定的数值预报增量，事先冻结）
- **依据：**
  - G1 诊断发现，GFS 的误差主要是幅度偏差，相位信息很少；
  - 误差集中在爬坡段；
  - 文献也指出，数值预报的系统偏差随时效变化不大。
  - 所以"预报变化量"可能比"预报绝对值"更可靠：做差能抵消缓变的偏差，再锚定在当前实测功率上。
- **功率曲线 PC_i：**
  - 每台机单独建一条，只用拟合段；
  - 横轴是 GFS 历史通道的原始风速（m/s，从准备阶段的逐小时数组取，保留 NaN，不能用数据包里归一化后的 0 反推），纵轴是实测小时功率；
  - 0.5 m/s 分箱取中位数，每箱至少 30 个样本；有效箱之间线性插值，超出范围取端点；
  - HoT 用全部拟合样本，改造标志仍留在特征里。
- **特征**（g(t0+h) 取 gF 第 5+h 列，h = 1–4；任何一项输入无效就记为 NaN，交给 LightGBM 原生处理缺失）：
  - PCL（对照）：PC(g(t0+h))，h = 1–4，再加 PC(g_hist(t0))，共 5 个；
  - ANI：ΔP_h = PC(g(t0+h)) − PC(g_hist(t0))，共 4 个；锚定预测 clip(P(t0) + ΔP_h, 0, 额定)，共 4 个；合计 8 个。
- PCL 和 ANI 都只是对 A1 已有输入做确定性变换，没有引入任何新信息。所以它们带来的增益，只能说明信息利用得更好。

**参加比较的臂**（LightGBM，代码路径与 A1 相同，只通过选列来区分）

| 臂 | 信息集 | seed 数 |
|---|---|---|
| L0 | 只有本场 SCADA | 1 |
| LU | 本场 + 上游 | 1 |
| LG | 本场 + GFS | 1 |
| LUG | 本场 + 上游 + GFS = 完整 A1 信息集（参照） | 3 |
| LUG+PCL | LUG + PCL | 3 |
| LUG+ANI | LUG + ANI | 3 |

**所有臂完全相同的设置（事先设定）**
- **开发验证段一分为二，前半段 V1 用于早停和网格选择，后半段 V2 只用于判定：**
  - Kelmarsh：V1 = 2021-01 至 06，V2 = 2021-07 至 12；
  - Penmanshiel：V1 = 2020-01 至 06，V2 = 2020-07 至 12；
  - HoT：V1 = 2023-07 至 09，V2 = 2023-10 至 12。
  - 窗口的目标时刻都必须落在同一段里，跨界的窗口两边都不用。
- **网格：** 与 A1 相同的 4 组。用 seed 2024 在 V1 上选组合，seed 2025、2026 用选中的组合再拟合。learning_rate 0.05，最多 4000 棵树，早停 200 轮，feature_fraction 0.8，bagging 0.8（freq 1），固定 8 线程，deterministic。
- **损失：** 每个窗口取 4 个时距的平均绝对误差；3 个 seed 的臂先在 seed 上平均窗口损失。

**判定规则（只看 V2，事先设定）**
- **门槛 1（在完整 A1 之上有增益）：** LUG+ANI 对 LUG，每个风场 MAE 都降低 ≥ 1.0%，并且三场按逆方差合并后的增益，95% CI 下界 > 0。统计用 paired_loss_statistics（块长 8，5000 次，seed 2024）。
- **门槛 2（起作用的是锚定本身）：** LUG+ANI 对 LUG+PCL，合并 CI 下界 > 0，而且至少 2 个风场的增益 > 0。
- **门槛 3（能迁移到神经网络，门槛 1、2 都通过才做）：** 在相同的 V1/V2 规则下重训 N 和 N+ANI（ANI 的 8 个特征像 GFS 常数一样沿 24 步广播），各 3 个 seed，按门槛 1 的规则判定。
- **结果和对应的写法：**

| 结果 | 论文怎么写 |
|---|---|
| 门槛 1、2、3 都通过 | 可迁移的信息利用方法（开发期证据，另附测试集上的探索性结果） |
| 门槛 1、2 通过，门槛 3 不通过 | 一种适用于树模型的数值预报利用方式，不称"可迁移" |
| 门槛 1 通过，门槛 2 不通过 | 只是功率曲线变换这类特征工程 |
| 门槛 1 不通过 | 负结果，论文定位为实证研究 |

- **接近通过时（事先设定）：** 三场增益都 > 0，但有的风场不到 1%，按用户的规则最多再做 2 轮，每轮在跑之前登记。候选变体：功率曲线横轴改用机舱风速；增量改成比值形式。

**只作描述**
- 在 V2 和已暴露的测试集上，计算 LightGBM 上的四项信息贡献：U = LU − L0，G = LG − L0，U|G = LUG − LG，G|U = LUG − LU。再和 N 上的 2×2 结果对照，看信息结论换了预测器是否仍成立。
- 已暴露的测试集上，所有臂只评一次，结果一律标"探索性"，不用于任何选择。

## 风险（≤5 条）

1. V2 样本少（Kelmarsh 和 Penmanshiel 各半年，HoT 只有一个季度），1% 的差异单场可能测不出来，所以用三场合并的 CI 来判定。
2. ANI 和已有文献（MOS、数值预报订正、持续法与数值预报混合）思路接近，新意有限。写论文前要先查清文献，再定措辞。
3. 树模型已经能用 GFS 的多列加上当前功率，近似算出差分，ANI 的增益可能很小。
4. V1/V2 的切分和 A1 原来的早停方式不同，所以 LUG 的结果会和 A1 原结果略有差异。X2 内部的比较一律只用 LUG 作参照。
