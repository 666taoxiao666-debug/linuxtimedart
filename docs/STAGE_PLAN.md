## 假设与判定标准

**评估集：** 与 N 完全相同的四个测试集（Kelmarsh 2022、Penmanshiel 2021、HoT 2024、HoT 2025），数据包和 N 的预测都按 x1_protocol 核对 SHA。统计方法同 A0。"N 优于该基线"的标准是：四个测试集的增益都 > 0，且 CI 下界都 > 0。

**A2 GFS + 功率曲线（R1-B1 决议）**
- 拟合曲线只用 gF_mask = 1 且功率有限的目标格子；拟合段加验证段一起用；HoT 只用改造后的样本。
- 预测时，gF_mask = 0 的格子退回持续法（起报时刻功率）。各测试集报告回退格子的数量。不删任何窗口。

**A1 LightGBM**
- 网格同第一版：num_leaves 和 min_child_samples 各 2 个取值，共 4 组。lightgbm 由 Cursor 装好后就跑。
- GFS 缺测格子保持占位 0，同时把 gF_mask 作为特征，与 N 的输入方式相同。
- 验证段和测试集的预测都要存盘（C1 要用）。

**A3 Chronos-2 零样本（R1-D1 决议，规格就此定死，不再单独审）**
- 模型身份：Cursor 回执里的 revision 和 manifest SHA；运行时逐个文件核对。
- 输入：
  - 把数据包里的归一化值用冻结的均值和尺度还原成原始单位；
  - 目标为功率；
  - 过去协变量：机舱风速、上游 11 个特征和缺测标志、GFS 历史通道；
  - 未来协变量：gF[:, 6:10]（m/s），缺测格子填 NaN。
- 点预测取 0.5 分位，另外存 0.1 和 0.9 分位（B2b 要用）。
- A3a 用 24 h 上下文；A3b 用 168 h 上下文，没有现成的逐小时序列就记"未做"。
- 对测试集、拟合段和验证段都做推理并存盘（B2、C1 要用），只用 GPU 推理。

**E1 全场加总口径（只描述）**
- 现有窗口是每 3 台机组错开一小时起报的，不能直接加总。所以用冻结的准备函数，只把步长改成 1，重建测试集窗口，再用冻结模型重新推理 N、N0、B，以及 A0、A2。
- 等价核对：新旧窗口重合的部分，预测与存盘预测相差 ≤ 0.01 kW，否则停。
- 指标：
  - 对每个起报时刻、每个时距，把在场机组的预测和实测分别加总；
  - 只保留在场机组 ≥ 80% 的起报时刻，按在场机组的总容量归一化；
  - 报告 1 − nRMSE、nMAE（分时距和总体），以及保留下来的起报时刻数。

**E2 正常运行子集（只描述，所有臂用同一组格子）**
- 异常格子的定义（事先设定，依据目标时刻的实测数据，只用于筛选评估样本）：
  1. 停机：机舱风速 ≥ 4 m/s，且功率 ≤ 1% 额定；
  2. 限功率或降额：风速在 6–25 m/s 之间，且功率 < 该机组拟合段分箱中位功率曲线的 50%。
- 同时报告全部样本和正常子集的结果，以及剔除的比例。

**B 大模型探索（一次性登记，取代逐轮；只作探索）**
- B1 Chronos-2 微调：用官方包自带的微调接口（有的话），默认超参数，按验证段 MAE 选检查点；包里没有这个接口就记"未做"。
- B2 堆叠，3 个变体 × 3 个 seed × 3 个风场 = 27 次拟合，配方同 N：
  - B2a：N 加 4 个通道，内容是 Chronos-2 的中位数预测；
  - B2b：N 加 12 个通道，是 0.1、0.5、0.9 三个分位；
  - B2c：在 Chronos-2 中位数之上学残差，输入同 B2a。
- 判定（事先设定，只看开发验证段）：
  - 选三场验证 MAE 平均改善最大的变体；
  - 如果它在三场都比 N 改善 ≥ 1%，算"有苗头"，报告测试集结果（写"探索性"）；
  - 否则写成负结果，不再加轮次。

**C1 组合预测（事先登记，测试集已用过，作描述）**
- 候选：N 集成（K/P 用 3 个 seed，HoT 用 5 个）、A1、A3a。
- 权重：非负、和为 1，以 0.1 为步长做网格搜索；每个风场按开发验证段 MAE 选定，然后用到测试集。
- N 在验证段的预测用冻结模型推理得到，不重训。
