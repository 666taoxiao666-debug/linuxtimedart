## 阶段名

N1-PH2：PH 路线的一轮有边界的优化（只做这一轮）。属于开发证据。

背景（用户 2026-11-05："负收益不大，不能一有负收益就换，太糟糕才应该换"）：
- 回看前几次停止：
  - K1b：先验在两个底座上都输给了通用注意力；
  - D2-0：光是曲线这一步的误差就超过了门槛；
  - N0：8 个留出站全部变差。
  - 这几次都是方向上的明确失败。
- N1-PH 不一样，是"差一点"，并且有一个具体线索：
  - 零样本时 RMSE 改善约 3%，MAE 变差约 2%；
  - 本场替换后，丢掉了约 35% 的上游增益（3.9/11.2 kW）。
- 两个具体解释，各对应一个最小修改：
  1. **损失不匹配**：PH 用 MSE 训练，偏向压大误差；风场以 0.8·MAE + 0.2·MSE 训练，并按 MAE 评估。改为同样的混合损失重训 PH（PH-mix）。
  2. **信息损失**：4 个 PH 通道替换掉了 11 维原始特征。改为两者都保留（通道集 ph+h）。
- 防止无限调参（事先设定）：
  - 变体选择只用 Kelmarsh 2020 验证年，不看 Penmanshiel 的任何标签；
  - 门槛与 N1-PH 完全相同；
  - 这一轮做完，PH 路线不再做第二轮优化。

## 目标

1. 在一个事先固定的小搜索空间里（4 个变体），只用源风场的验证年选出一个变体。
2. 对选中的变体，用 N1-PH 原样的门槛（ZP、ZQ、F1P、F3P、IP）在 Penmanshiel 2021 年评估一次。
3. 如实报告全部 4 个变体的结果（描述性的），不按结果改选。

## 假设与判定标准

- **变体空间**（2 × 2，事先固定）：
  - PH 的损失：mse（即 N0 冻结的 PH，SHA256 584fa1e9…）或 mix（0.8·MAE + 0.2·MSE）。
  - 风场通道集：
    - ph：14 个通道（N1-PH 原样）；
    - ph+h：8 个非功率 SCADA + 11 维原始 H + 4 个 PH + upstream_missing + 功率，共 25 个通道。
  - V0 = (mse, ph)，即 N1-PH 原配方，复用它的拟合和数组。
- **PH-mix 怎么训**：沿用 N0 的流程和 28 个训练站（拟合 2016–2019，验证 2020 早停，seed 2024），只换损失函数；结构、输入、站点划分都不变。
  - 冻结后记录 SHA，并在站网上报告它和 PH-mse 的本站与迁移数字，作为描述。
- **选择规则**（事先设定，不用目标风场标签）：对每个变体，用 Kelmarsh 数据训练 K-变体（拟合 2016-05–2019，验证 2020，3 个 seed）。
  - 取 Kelmarsh 2020 验证 MAE 的 3 seed 平均，最低者入选。
  - 差距 < 0.5 kW 时，选通道少、改动少的那个（顺序 V0 < (mix, ph) < (mse, ph+h) < (mix, ph+h)）。
- **评估选中变体**：与 N1-PH 完全相同——
  - 主折为 Penmanshiel 2021；
  - ZP、ZQ、F1P、F3P 在开发比较族内做 Holm；
  - IP 非劣界为 −2 kW；
  - 判定"继续 / 部分 / 停止"的规则不变。
  - 如果选中的是 V0，直接沿用 N1-PH 的结论（停止），不重复评估。
- **只描述**：全部 4 个变体在主折的 K-变体零样本数字（ZP、ZQ 方向）；选中变体在 T22、T23 折上的数字。
- **表述**：通过只算"开发支持"。这些变体是看过 N1-PH 的 2021 结果之后提出的，存在选择偏差，论文里要如实写；确认必须用第三个风场。
