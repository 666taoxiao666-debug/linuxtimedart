## 目标

1. 给论文补上外部对照：持续法、LightGBM、数值预报加功率曲线、时序大模型 Chronos-2（零样本）。回答"N 是否优于这些常用方法"。

## 假设与判定标准

**评估集（与 N 完全相同的窗口，标签不动）**
- Kelmarsh 2022（16949 窗）、Penmanshiel 2021（38147 窗）：G1 path_T 的测试年；N 的预测取 G1 formal 存盘的 prediction.npy，SHA 按 completed.json 核对。
- HoT 2024（59587 窗）、2025（56857 窗）：G2c 的数据包和存盘预测。
- 每个基线的所有选择只用各自风场的开发段（拟合段 + 验证段），切分与 N 相同；HoT 用情形 A 的切分。

**A 线：外部基线（事先登记，结论进论文对照表）**
- A0 持续法：预测 = 起报时刻的功率。
- A1 LightGBM：
  - 每个风场单独训练，每个时距一个模型，目标函数 L1。
  - 特征与 N 用同一信息集：起报时刻那一行的全部通道（N 的 50 个通道，HoT 再加改造标志）、过去 24 h 的功率和机舱风速两条序列、机组编号（类别特征）。不加日历特征（N 也没有）。
  - 网格（事先设定）：num_leaves ∈ {31, 127} × min_child_samples ∈ {50, 200}。learning_rate 0.05，最多 4000 棵树，验证段早停 200 轮；feature_fraction 0.8，bagging_fraction 0.8，seed 2024。按 4 个时距平均的验证 MAE 选组合。
- A2 数值预报 + 功率曲线（物理-统计基线）：
  - 每台机建一条曲线："目标时刻 GFS 风速 → 实测功率"，0.5 m/s 分箱取中位数。GFS 风速用与 N 相同的风场中心点当前周期插值，即 gF 第 6–9 列。
  - 样本少于 30 的箱用相邻箱线性插值，超出范围取端点。
  - 这个基线没有可调参数，所以用拟合段加验证段的全部开发数据建曲线，对基线有利。HoT 只用改造后的样本，因为测试年全是改造后。
- A3 Chronos-2 零样本（时序大模型作为基线）：
  - 模型 amazon/chronos-2（120M 参数，Apache-2.0），版本固定为 Cursor 下载时记录的 revision。
  - 目标序列：该机组功率（kW，原始单位）。
  - 过去协变量：机舱风速、11 个上游特征和缺测标志、GFS 历史通道。
  - 已知未来协变量：4 个目标时刻的 GFS 风速。
  - 点预测取 0.5 分位，不调参。
  - A3a：上下文 24 h，与 N 信息相同，作主对照。
  - A3b：上下文 168 h，只描述。需要用冻结的准备函数重建逐小时序列；如果做不到，就记"未做"，不影响 A3a。
- **A 线统计与判定（事先设定）：**
  - 每个测试集都比较 N（前 3 个 seed 的损失平均，同 G1、G2c）和每个基线。用 paired_loss_statistics：块长 8，5000 次，seed 2024，NW 滞后 7。
  - "N 优于该基线" = 4 个测试集的增益都 > 0，且 CI 下界都 > 0。否则按测试集分别如实报告。
  - 同时报告各基线的 MAE、RMSE、R²、准确率（1 − nRMSE，按各场额定功率）和分时距 MAE。

**B 线：大模型探索（只作探索，选择只看开发验证段）**
- B1 Chronos-2 微调：用各风场拟合段微调（官方微调接口，默认超参数，按验证段 MAE 早停），输入同 A3a。只与 A3a、N 比较，作描述。
- B2 堆叠（"大模型 + 本方法"）：
  - 在 N 的输入里加 4 个通道，内容是 A3a 的零样本中位数预测，像 GFS 常数一样沿 24 步广播；其余配方与 N 相同，3 个 seed（2024–2026）。
  - 为此需要先对拟合段和验证段跑一遍 A3a 推理。
- **B2 判定（事先设定，只看开发验证段）：**
  - 三个风场的验证 MAE 都比 N 低 ≥ 1%，算"有苗头"。之后按用户偏好最多再做 2 轮优化，每轮事先登记。
  - 否则写成负结果："大模型堆叠在强基线上没有增量"。
- B 线在测试集上的数字只能写"探索性，测试集已用过"，不进对照表的结论。

**执行顺序**
- A0、A2 先跑（CPU，没有新依赖）；A1 等 lightgbm 可用；A3 和 B 线等 Cursor 装好 Chronos-2，Codex 核验之后再跑。
- 各部分跑完分别取回，互不等待。
