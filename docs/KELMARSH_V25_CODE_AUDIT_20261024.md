## 数据与方法核查

- 输入为 24 小时历史、输出未来 4 小时功率；历史有效性、目标有效性和跨风机/时间连续性筛选与 v20 共用。未来气象列不进入模型或目标有效性筛选。
- 标准化继续使用 v20 外层训练前 60% 的固定 scaler；模型 fit 使用外层训练前 90%，最后 10% 只做内部 epoch 选择。没有把 scaler 扩到验证或封存段。
- `KelmarshSeries` 读取原 CSV 后截去封存 suffix；A0–A2 只请求 fit/selection，G2 通过后才请求外层 validation。原始 CSV 读取不等于对封存样本做推理；本轮不计算封存指标。
- Full 与 PowerOnly 的初始化、参数量、批次/训练预算和窗口完全相同；PowerOnly 仅在模型输入端将已标准化辅助通道置零。两者都保留相同缺失值筛选，防止比较队列变动。
- 3,618 参数的两块 MLP 与官方 basic TSMixer 的时序/通道混合、归一化轴、残差及输出投影对应；这是一种固定小配置的 PyTorch 移植，不能称官方最优配置复现，也不是新的 Wiki 贡献。
- G1/G2 是内部开发预算门槛，不是显著性检验。失败必须停止扩展；通过也不能把历史上已查看的外层验证集称为独立确认集。信息消融说明辅助通道整体价值，不是单通道因果证明。
- 配对统计按共同 issue 时间组成天气块，避免把同步多风机、步长与 seed 当作相互独立样本；保留 bootstrap、HAC/Newey–West 和 Holm 结果，不挑显著的检验。
